① 绝对单位 px

px (pixel) 固定像素，不受任何字体设置影响

显示器上一个像素点。写多少就是多少，不会随着浏览器缩放或根字体变化。

② em（相对父元素）vs rem（相对根元素）

em —— 相对于父元素的 font-size

⚠️ em 在嵌套时会产生「放大效应」：父 24px → 子 1em=24px → 孙子 1em=子的 1em 还是 24px，但 padding:1em 会层层传递放大。

L1: font-size: 24px
L2: font-size: 1em (=24px)
L3: font-size: 1em (=24px)
但 padding:1em 每一层都放大！

rem —— 相对于 html 的 font-size（root em）⭐推荐

整个页面只有一个基准点：html { font-size: 16px; }。1rem = 16px，**不随嵌套放大**。

👇 点击按钮改变 html font-size，看 rem vs px 谁会跟着变：

width: 12rem
✅ rem：跟着变
width: 192px
❌ px：不变
html font-size: 16px → 1rem = 16px
③ vw / vh —— 视口百分比

vw (viewport width) · vh (viewport height)

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。拖动浏览器窗口大小看看效果！

④ % —— 父容器百分比

%

相对于父容器的尺寸。父容器变它就变，父容器多大它就相对多大。

父容器 width: 100%
子 50% → 父的一半
孙子 50% → 父的 50% = 爷的 25%

💡 选型建议

• px：边框、阴影、固定小图标尺寸

• rem：推荐作为主力单位，padding/margin/字体/容器宽度全用它，改根字号全站响应

• em：仅在想让某个子元素跟随父元素 font-size 变化时用（如按钮内部 padding）

• vw/vh：全屏 Banner、视口高度布局（100vh）、文字 clamp()

• %：父容器内部的流式分栏
