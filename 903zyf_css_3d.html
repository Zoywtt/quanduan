① 旋转立方体

transform-style: preserve-3d 让子元素真正处在 3D 空间

6 个面各 translateZ(110px) 向外偏移，父容器 rotateX + rotateY 同时旋转。

.cube { transform-style: preserve-3d; } .cube { animation: spin 12s infinite linear; } /* 每个面 */ .front { transform: translateZ(110px); } .back { transform: rotateY(180deg) translateZ(110px); }

② 3D 翻转卡片

backface-visibility: hidden 背面不可见 + hover rotateY(180deg)

鼠标悬停卡片会翻转到背面。点击也可切换（支持触屏）。

.card { transform-style: preserve-3d; transition: transform 0.8s; } .card:hover { transform: rotateY(180deg); } .side { backface-visibility: hidden; position: absolute; } .back { transform: rotateY(180deg); }

③ 旋转木马 Carousel

rotateY + translateZ 围成一圈

每张卡片 rotateY 递增 45° 再 translateZ 到同一个圆周上（这里 8 张，每张 45°）。hover 暂停。

.item { transform: rotateY(0deg) translateZ(200px); } .item:nth-child(2) { transform: rotateY(45deg) translateZ(200px); } /* 依次 +45° */
