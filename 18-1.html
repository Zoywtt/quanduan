JSON 数据格式

JavaScript Object Notation —— 轻量级的数据交换格式

01JSON 的语法结构
一个 JSON 数据由「键值对」组成，键必须用双引号包裹，值可以是 6 种类型之一。
{ "name": "张耀夫", "studentId": "24001010903", "age": 20, "graduated": false, "avatar": null, "skills": ["HTML", "CSS", "JavaScript"], "scores": { "html": 95, "css": 92, "js": 88 } }
02JSON 只支持 6 种数据类型
没有 undefined、没有函数、没有 Date、没有注释 —— 这是 JSON 与 JS 对象最大的区别。
string 字符串
"hello"
number 数字
3.14
boolean 布尔值
true
null 空值
null
object 对象
{ "k": 1 }
array 数组
[1, 2, 3]
03JSON 的 4 条严格规则
  • 键名必须用双引号：{ "name": "张三" } ✅  |  { name: '张三' } ❌
  • 不允许注释：// 说明 和 /* 说明 */ 在 JSON 里都是非法字符
  • 不允许尾随逗号：[1, 2, 3,] 与 { "a": 1, } 都会解析失败
  • 不允许特殊值：undefined、函数、NaN、Infinity 都不能出现

05JSON.stringify() 与 JSON.parse()
两者互为逆操作：对象 → 字符串（序列化），字符串 → 对象（反序列化）。这是前后端传输数据的核心方法。
