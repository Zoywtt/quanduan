异步流程演示：包饺子

买原料 → 取原料 → 同时和面、和馅 → 两者都完成才包饺子 → 吃饺子

和面与和馅并行执行，用 Promise.all 等待全部完成
每一步都用 setTimeout 模拟耗时，进度条实时显示
Promise

Promise 链式写法

用 .then() 串联每一步，并行步骤交给 Promise.all
当前阶段：等待开始
--:--:--等待开始… 
买原料()
  .then(取原料)
  .then(() => Promise.all([和面(), 和馅()]))
  .then(包饺子)
  .then(吃饺子)
async / await

async/await 写法

用 await 等待每一步，代码像同步一样从上往下读
当前阶段：等待开始
--:--:--等待开始… 
async function 做饺子() {
  await 买原料();
  await 取原料();
  await Promise.all([和面(), 和馅()]);
  await 包饺子();
  await 吃饺子();
}
