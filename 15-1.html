方案 A · SVG 自适应下导航（固定贴底）

使用 flex: 1 等分宽度实现自适应；图标为 SVG，通过 fill: currentColor 继承父元素 color，用 CSS 一行代码同时改变图标和文字的颜色；激活项有缩放和阴影动效。

👋 欢迎来到「张耀夫 App」首页。
下方是 SVG 自适应下导航，点击试试高亮效果！
核心知识点：
· fill: currentColor 让 SVG 跟随文字变色
· flex: 1 1 0 等分自适应宽度
· position: absolute 实现固定贴底

方案 B · iconfont 字体图标下导航（待字体文件）

请在 font/ 目录下放入 iconfont 下载的字体文件和 iconfont.css， 然后在本页 <head> 中取消 link 的注释即可生效。结构和自适应布局与 SVG 方案一致， 只是图标换成 <i class="zyf_icon zyf_icon-home"></i>。
